# Next Template

Next.js 14 template with TypeScript, Tailwind CSS, and Devcontainer support.

## Getting started

Install dependencies:

```bash
npm install
```

Run dev server:

```bash
npm run dev
```

Then open http://localhost:3000

## Devcontainer

Open this folder in VS Code and run:

"Dev Containers: Reopen in Container"

Or use GitHub Codespaces and select this repo.
